## 条件

- 全方式 Modal T4 1枚、1 CPU、8 GiB。Whisper large-v3、言語 `ja`、beam size 5、前のテキストを引き継がない設定。バッチ版以外は VAD なし。
- `faster-whisper==1.2.1`、CTranslate2 float16、モデル `Systran/faster-whisper-large-v3@edaa852ec7e145841d8ffdb056a99866b5f0a478`。
- `whisper.cpp` commit `d1be6fde11ac6e0407606b4e42fe72d34add8037`、CUDA arch 75、非量子化 `ggml-large-v3.bin@ggerganov/whisper.cpp:c521a4b02f422512d734391fdf08bb08c0862f68`。

- OpenAI `whisper-1` の出力との文字列一致率は参考値。正解字幕を人手で作っていないので、WER や客観的な正解率ではない。

## 判断

固定30秒区切りのバッチ版は欠落があるため使用しない。後述の追試で、無音境界と欠落検出・局所再処理を加えたバッチ方式を作った。5分では whisper.cpp より逐次 faster-whisper が速く安い。全編単発では whisper.cpp が約7%速く約10%安かったが、単回測定なので優劣の一般化はできない。PyTorch 版はこの T4 では遅い。

再実行スクリプト: `apps/worker/scripts/modal_whisper_backends_poc.py`。`VIDEOQ_POC_BACKEND=cpp` のように対象を環境変数に設定し、`modal run ... --backend cpp --audio-path <音声> --output-path <JSON>` で実行する。逐次版は `apps/worker/scripts/modal_whisper_poc.py`。初回比較時は本番コードと DB を変更していない。

## 追試: 無音境界と欠落区間の再処理

VAD は音声を除去せず、30秒以下の区間を無音位置で切るためだけに使った。バッチ認識後、VAD が発話と判定した時間帯に1秒を超える字幕の空白があれば、その区間を含むクリップだけ逐次認識し直して差し替える。無音位置を選べなかった場合は5分全体を逐次認識する。この方式は `apps/worker/modal_batched_whisper.py` に実装した。

| 同じ large-v3 / T4 | バッチ＋局所再処理 | 逐次版 | 本文の一致率（逐次版を基準） |
| --- | ---: | ---: | ---: |
| 冒頭5分 | 推論17.34秒、実費 $0.005065 ≈ 0.81円 | 推論23.67秒、$0.005455 ≈ 0.87円 | 99.16% |
| 中盤5分（600〜900秒） | 推論20.17秒、実費 $0.005065 ≈ 0.81円 | 推論22.22秒 | 98.03% |
| 全編29分29秒 | 推論93.44秒、実費 $0.019482 ≈ 3.12円 | 推論147.32秒、$0.030785 ≈ 4.93円 | 98.62% |

冒頭5分で1クリップ、中盤5分で2クリップ、全編で5クリップを再処理した。中盤5分で固定分割や無音分割だけでは抜けた「その各標本点に対する」「標本化間隔をこれぐらいのこの1個ですね」を復元できた。全編には短い語句の違いや省略が残り、正解字幕による客観的な精度評価は未実施。費用は Modal 請求行の実費で、クレジット控除前、$1=160円の予算換算。

### VideoQ での使用

認証付き Modal API `videoq-batched-whisper` をデプロイし、OpenAI SDK 互換の `/v1/audio/transcriptions` を5分音声で確認した。VideoQ ワーカーから69字幕を受け取り、SRT パーサーでも69件を処理できた。無効な Bearer トークンは401。Modal Secret 名は `videoq-whisper-auth`、環境変数名は `VIDEOQ_WHISPER_TOKEN`。秘密値はリポジトリに含めない。

ワーカー側は `WHISPER_BACKEND=modal`、`WHISPER_MODAL_URL`（`/v1` を含まない Modal API のルート URL）、`WHISPER_MODAL_TOKEN` で切り替える。これらは本番の SSM app SecureString に格納できる。従来の OpenAI 経路は `WHISPER_BACKEND=openai` または未指定で使える。ワーカーの本番イメージと SSM のバックエンド設定はまだ切り替えていない。

Modal サービスを再デプロイするには、Modal 認証済み環境で `uvx --from modal --with fastapi==0.115.12 modal deploy apps/worker/modal_batched_whisper.py` を実行する。`max_containers=4` で4本の SQS 処理レーンに上限を合わせ、アイドル時はGPUを縮退する。
